Agent control plane

Submit and cancel coding tasks from a Marble document without exposing a raw shell endpoint.

  • Authenticated job API
  • Agent session document inside Drive
  • Progress, tool calls, and audit log
  • One allowlisted repository per task
No code execution yet

Isolated coding worker

Give the agent full coding tools inside a disposable worktree instead of the live checkout.

  • One Git worktree and branch per task
  • Sandboxed commands and resource limits
  • Scoped environment variables
  • Tests, diff, cancel, and cleanup
Machine boundary

Live preview and promote

Watch the isolated interface change immediately, then move the finished result into the main repository.

  • Private preview host per session
  • Authenticated proxy through Drive
  • Live updates without page reloads
  • Promote, reject, and one-step rollback
Agent usable release
Roadmap meaning

The coding agent is a single-owner extension to today’s host. It does not complete G4 “local-first, desktop, agent as peer,” because the G4 synchronization protocol still remains future work.
